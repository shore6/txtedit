# txtedit

`.txt` 専用の軽量メモアプリです。Cloudflare Workers + D1 上で動き、どの端末からでも同じメモを編集できます。

- **軽量**: ビルド不要の素の JS / CSS。アプリ本体は約 70KB（gzip 後 約 20KB）、外部ライブラリなし
- **同期**: 編集は約 1 秒後に自動保存。他の端末の変更は、画面に戻ったとき・30 秒ごと・オンライン復帰時に取り込み
- **オフライン編集**: 内容は端末の IndexedDB にも保存。オフラインでも起動・編集でき、オンラインに戻ると自動で送信
- **コンフリクトのマージ**: 行単位の 3-way マージ。別の行の変更は自動で統合し、同じ行の変更だけを「自分 / サーバー / 両方」から選ぶ画面を出す（マーカー付きで手動編集も可）
- **検索**: ファイル名と本文を全文検索（スペース区切りで AND）。端末内のデータを検索するので即時に結果が出て、オフラインでも使える
- **フォルダ**: `フォルダ/サブフォルダ/名前.txt` 形式のパスで階層化。フォルダの名前変更・移動・削除に対応
- **PWA**: スマホのホーム画面に追加してアプリとして使える
- その他: `.txt` の取り込み（ボタン / ドラッグ＆ドロップ）、ダウンロード、ダークモード

## デプロイ

Cloudflare アカウントと Node.js 18 以上が必要です。費用は無料枠でほぼ足ります。

```bash
npm install
npx wrangler login
```

D1 データベースを作成し、表示された `database_id` を `wrangler.toml` に書き込みます。

```bash
npx wrangler d1 create txtedit
```

ログイン用のトークンを登録します。ランダムな長い文字列にしてください（例: `openssl rand -hex 32` の出力）。

```bash
npx wrangler secret put AUTH_TOKEN
```

マイグレーションを適用してデプロイします。

```bash
npm run deploy
```

表示された `https://txtedit.<アカウント>.workers.dev` を開き、トークンを入力すると使えます。

### Cloudflare Access の併用（推奨）

ダッシュボードの Zero Trust → Access → Applications で、この Worker のドメインにメール認証のポリシーを設定すると、トークンの手前にもう 1 段ログインを挟めます。アプリ側の変更は不要です。

## ローカル開発

```bash
echo 'AUTH_TOKEN=devtoken' > .dev.vars
npm run dev
```

http://localhost:8787 を開き、`devtoken` でログインします。

マージ処理のテストは次で実行します。

```bash
npm test
```

## 仕組み

| 場所 | 役割 |
|---|---|
| `src/worker.js` | API（`/api/changes`, `PUT/DELETE /api/files/:id`）。それ以外のパスは静的ファイルを配信 |
| `migrations/` | D1 のスキーマ |
| `public/sync.js` | 同期エンジン（差分取得・送信・競合の調停） |
| `public/merge.js` | 行単位の diff（Myers 法）と 3-way マージ |
| `public/store.js` | IndexedDB の薄いラッパー |
| `public/sw.js` | Service Worker（アプリ本体のキャッシュ） |

- 各ファイルは `version` を持ちます。保存時に「編集を始めたときの version」を送り、サーバー側と一致したときだけ更新します（楽観ロック）。一致しなければサーバーは最新の内容を返し、クライアントが 3-way マージします。
- 他の端末の変更は、全体で単調に増える `seq` 番号を使って差分だけ取得します。削除も論理削除として伝わります。
- ファイル ID はクライアントで生成する UUID なので、オフラインで作ったファイルも後からそのまま登録できます。

## 制限

- 1 ファイルあたり 1MB まで
- フォルダは、中のファイルのパスから自動的に作られます。中身が空のフォルダは保持されません
- 同じ端末の複数タブで同時に編集すると、タブ間でも競合として扱われます（データは失われず、マージ画面が出ます）
- アプリ本体を更新した場合、各端末に反映されるのは 2 回目の読み込み時です
